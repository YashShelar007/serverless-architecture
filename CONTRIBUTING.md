# Contributing

This repo is archived and not taking new features. Fixes to the docs or config are welcome.

1. Try a function locally: `cd functions/users && python3 -c "import main; print(main.get_users(None))"`.
2. There is no test suite; deploying needs a GCP project, see the README.
3. Branch from `main`, keep the change small, and open a pull request that says what you ran.
